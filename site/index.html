What it gets right

Each response once

Claude Code writes one API response as several transcript entries, each repeating its usage. Summing entries roughly doubles every figure; agent-ledger counts by message ID.

Cache priced by TTL

Cache writes are 1.25× for five minutes and 2× for an hour; reads are 0.025× to 0.1× depending on the model. The transcript says which — so the cost does too.

Subagents included

A subagent's transcript sits beside its parent's. Its tokens land in the session that launched it, so a cheap-looking session that fanned out shows its real cost.

Unknown is not free

A model with no price in the dated table is marked and left out of the total — never silently priced at zero.

On a subscription

Pro and Max are not billed per token. There the cost column is what the same traffic would cost on the API: a way to compare tasks, models and habits, not your bill.
